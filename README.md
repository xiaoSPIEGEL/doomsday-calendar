# Doomsday: Last Survivors - Alliance Event Tracker

A sleek, interactive web calendar designed for the **Doomsday: Last Survivors** community. Created and maintained by **xiaoSPIEGEL**.

This tool accurately calculates the cycle of every major in-game event (Water War, Alliance League, Raids, etc.) based on their specific weekly, bi-weekly, and monthly rules. No more guessing when the next Off-Limits War starts!

**Live Website:** [https://xiaospiegel.github.io/doomsday-calendar/](https://xiaospiegel.github.io/doomsday-calendar/)

## Features

- **Auto-Calculating Events:** Advanced logic built directly into the code to predict event cycles until December 2027.
- **Live UTC Game Clock:** A real-time, monospaced clock synced to the game's server time (GMT+0) so you never miss a reset.
- **Custom Sci-Fi Dark Mode:** A unique, sleek UI featuring custom fonts (Orbitron & Share Tech Mono) and a tactical layout.
- **Today Highlight:** The current day pulses smoothly and features a breathing user icon, making it easy to spot at a glance.
- **Mobile Friendly:** The layout automatically stacks on smaller screens for easy checking on the go.
