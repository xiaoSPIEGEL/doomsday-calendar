# Doomsday: Last Survivors - Alliance Event Tracker

An interactive, auto-updating calendar designed specifically by **XIAOSPIEGEL** for *Doomsday: Last Survivors*. 

This tool automatically calculates the cycle of every major in-game event (Water War, Alliance League, Raids, etc.) based on their specific weekly, bi-weekly, and monthly rules. No more guessing when the next Off-Limits War starts!

**Live Website:** [https://xiaospiegel.github.io/doomsday-calendar/](https://xiaospiegel.github.io/doomsday-calendar/)

## Features
- **Auto-Calculating Events:** Logic built directly into the code to predict event cycles until December 2027.
- **UTC Game Clock:** A real-time clock synced to the game's server time (GMT+0) so you never miss a reset.
- **Dark Mode UI:** A sleek, custom dark theme designed to be easy on the eyes.
- **Mobile Friendly:** The layout automatically stacks on smaller screens for easy checking on the go.
